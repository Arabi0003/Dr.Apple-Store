# Dr. Apple — Kano, Nigeria

Production-grade management and retail platform for **Dr. Apple** stores in Kano, Nigeria.

## Features
- 🍎 Genuine Apple hardware showcase (iPhone, MacBook, iPad, Watch, AirPods)
- 📍 5 Branch locations across Kano
- 🇳🇬 Multi-language interactive typewriter (Hausa, Arabic, Chinese, English, French)
- 🌓 Dark / Light Mode with frosted glass aesthetics
- 🎥 Custom background video (`dr.mp4`) & custom logo (`dr.png`)
